# Damián | Gestión de cartera

Demo local de gestión de clientes, préstamos, cuotas, pagos y cartera.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Producción

```bash
pnpm run build
pnpm start
```

La demo guarda clientes, préstamos, cuotas y pagos en `localStorage` con la clave `cartera-demo-data`. Es una solución de demostración sin backend.
